# Quadro de desenvolvimento

Este quadro versionado permite acompanhar o trabalho localmente. O GitHub Project ainda precisa ser criado com acesso autenticado; este arquivo não configura o serviço remoto.

| A fazer                         | Em andamento                            | Em revisão | Concluído |
| ------------------------------- | --------------------------------------- | ---------- | --------- |
| Criar e vincular GitHub Project | Implantação dos processos (tasks 01–16) | —          | —         |

## Uso diário

- Cada item aponta para uma tarefa com problema, resultado esperado e critérios de aceite.
- Mova para **Em andamento** ao iniciar e mantenha uma tarefa ativa por pessoa, salvo dependências explícitas.
- Mova para **Em revisão** quando houver mudança revisável e evidências de validação.
- Mova para **Concluído** após atender a definição de pronto e integrar a mudança.
- Registre bloqueios no próprio item, com próximo passo e responsável.

## Configuração no GitHub

No perfil `PetersonFonsec`, abra **Projects → New project → Board**, nomeie `TaskGo — Desenvolvimento` e configure o campo Status com **A fazer**, **Em andamento**, **Em revisão** e **Concluído**. Vincule o projeto ao repositório `PetersonFonsec/TaskGo`. Adicione as issues e vincule os PRs correspondentes; confirme as quatro colunas e mova um item para validar o fluxo.

Registre aqui a URL depois da criação. Não há URL remota confirmada nesta execução.

Referência: [criação de Projects](https://docs.github.com/en/issues/planning-and-tracking-with-projects/creating-projects/creating-a-project).
