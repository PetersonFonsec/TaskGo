# Backend HTTP endpoint inventory

Inventário estático da Entrega 1. A autenticação efetiva depende dos guards e decorators de cada rota; `Público` abaixo indica uso explícito de `@Public` ou endpoint operacional público observado no controller.

| Contexto                    | Métodos e rotas                                                                                                                                                                                                                                                                                                                                      |
| --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Aplicação                   | `GET /`                                                                                                                                                                                                                                                                                                                                              |
| Autenticação                | `POST /auth/login`, `POST /auth/register`, `POST /auth/forget`                                                                                                                                                                                                                                                                                       |
| Usuários                    | `POST /user`, `GET /user`, `GET /user/:id`, `PATCH /user/:id`, `DELETE /user/:id`, `POST /user/:id/verify-email`, `POST /user/:id/verify-phone`, `POST /user/:id/confirm-email`, `POST /user/:id/confirm-phone`                                                                                                                                      |
| Endereços do usuário        | `POST /user/me/addresses`, `GET /user/me/addresses`, `GET /user/me/addresses/:id`, `PATCH /user/me/addresses/:id`, `DELETE /user/me/addresses/:id`                                                                                                                                                                                                   |
| Prestadores                 | `POST /provider`, `GET /provider`, `GET /provider/:id`, `PATCH /provider/:id`, `DELETE /provider/:id`, `GET /provider/:id/availability`, `GET /provider/by-category/:slug`                                                                                                                                                                           |
| Favoritos                   | `POST /favorites`, `GET /favorites`, `DELETE /favorites/:providerId`                                                                                                                                                                                                                                                                                 |
| Catálogo de serviços        | `POST /services`, `GET /services`, `GET /services/:id`, `PATCH /services/:id`, `DELETE /services/:id`                                                                                                                                                                                                                                                |
| Categorias                  | `POST /categories`, `GET /categories`, `GET /categories/:id`, `PATCH /categories/:id`, `DELETE /categories/:id`                                                                                                                                                                                                                                      |
| Pedidos                     | Os aliases `/order` e `/orders` atendem `POST /`, `GET /`, `GET /:id`, `GET /:id/summary`, `GET /client/:clientId`, `GET /provider/:providerId`, `PATCH /:id`, `DELETE /:id`, `POST /:id/schedule`, `POST /:id/provider/:providerId/confirm`, `POST /:id/provider/:providerId/cancel`, `PATCH /:id/finish`, `PATCH /:id/confirm`, `POST /:id/review` |
| Pagamentos                  | `POST /orders/:id/payment`, `GET /orders/:id/payment`, `POST /payments/webhook/pagarme`                                                                                                                                                                                                                                                              |
| Tags de avaliação           | `GET /review-tags`                                                                                                                                                                                                                                                                                                                                   |
| Feature flags               | `POST /feature-flag`, `GET /feature-flag`, `GET /feature-flag/:id`, `PATCH /feature-flag/:id`, `DELETE /feature-flag/:id`                                                                                                                                                                                                                            |
| Autenticação administrativa | `POST /admin/auth/login`, `POST /admin/auth/activate`, `GET /admin/auth/me`, `POST /admin/auth/change-password`                                                                                                                                                                                                                                      |
| Usuários administrativos    | `GET /admin/users`, `POST /admin/users/invitations`, `PATCH /admin/users/:id/role`, `POST /admin/users/:id/activate`, `POST /admin/users/:id/deactivate`                                                                                                                                                                                             |
| Prestadores administrativos | `GET /admin/providers`, `GET /admin/providers/:id`, `GET /admin/providers/:id/history`, `POST /admin/providers/:id/approve`, `POST /admin/providers/:id/reject`, `POST /admin/providers/:id/block`, `POST /admin/providers/:id/unblock`                                                                                                              |
| Dashboard administrativo    | `GET /admin/dashboard/providers`                                                                                                                                                                                                                                                                                                                     |
| Auditoria administrativa    | `GET /admin/audit-logs`, `GET /admin/audit-logs/:id`                                                                                                                                                                                                                                                                                                 |
| Operações                   | `GET /metrics`, Swagger em `/api`                                                                                                                                                                                                                                                                                                                    |

## Compatibilidade durante a refatoração

- Não remover o alias singular/plural de pedidos sem uma migração explícita dos consumidores.
- Não mudar status HTTP, formato de erro ou serialização de `bigint` incidentalmente.
- Não aceitar IDs de cliente ou prestador fornecidos na rota como substitutos da identidade autenticada quando o endpoint exige ownership.
- Atualizar este inventário quando uma mudança de contrato for deliberadamente aprovada.
